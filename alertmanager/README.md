\# Alertmanager



Alertmanager handles alerts generated by Prometheus and routes them to the configured notification channel.



\## Configuration



\- Service: `alertmanager`

\- Service User: `prometheus`

\- Port: `9093`

\- Executable: `/usr/local/bin/alertmanager`

\- Configuration: `/etc/alertmanager/alertmanager.yml`

\- Storage: `/var/lib/alertmanager/`



\## Alert Routing



Prometheus → Alertmanager → PagerDuty



Alerts are grouped by:



\- `alertname`

\- `instance`



Configured timing:



\- Group wait: 10 seconds

\- Group interval: 10 seconds

\- Repeat interval: 1 hour



\## Security



The PagerDuty routing key is \*\*not stored in Git\*\*.



It must be supplied securely at deployment/runtime using:



`PAGERDUTY\_ROUTING\_KEY`
